CF Submission
Fetcher

Pull source code from multiple Codeforces submissions at once — for personal study and analysis.

Install Script

Requires Tampermonkey browser extension  ·  Works in Chrome, Firefox, Edge

What this does

When you are studying competitive programming, one of the best ways to improve is to read accepted solutions from other contestants — especially on problems you attempted but couldn't solve. This script lets you go to any Codeforces contest status page, select multiple submissions at once, and pull all their source codes into a single view. You can then copy everything in one click and paste it into an AI model or your notes for deep analysis. It saves the repetitive work of opening each submission individually.

Features

☑
Checkboxes
Injected into every submission row. Select all or pick individually.
⬇
Batch Fetch
Fetches source from each submission page using your logged-in session.
⏱
Safe Delay
2-second countdown between each request to avoid rate limiting.
📄
Copy All
All sources merged into one block with clear separators. One click to copy.
📋
Copy Single
Each solution also has its own copy button for individual access.
🔐
No Login Needed
Runs inside your browser session — no API keys or credentials required.

How to install

1
Install Tampermonkey
Add the Tampermonkey extension to Chrome, Firefox, or Edge. It's free.
2
Create a new script
Click the Tampermonkey icon in your browser → Create a new script. Delete all default content.
3
Paste and save
Download the script above, open it, copy everything, paste into the editor, then hit Ctrl+S.
4
Go to any contest status page
Open codeforces.com/contest/XXXX/status/A while logged in. The floating bar appears at the bottom-right.
5
Select → Fetch → Copy
Tick checkboxes, click Fetch Sources, wait for the countdown, then hit Copy All.

Do not abuse this

⚠ Responsible use only
  • This script is for personal study — reading and understanding accepted solutions on problems you have already attempted.
  • Do not use it to copy solutions and submit them as your own. That is plagiarism and violates Codeforces rules.
  • Do not scrape hundreds of submissions in bulk. The built-in delay exists for a reason — respect it and don't bypass it.
  • Codeforces rate-limits aggressive scrapers. If you get blocked, that is on you — the delay is there to keep you safe.
  • This tool gives you no advantage in a live contest. It only works on the public status page, which requires the contest to be ongoing or finished.
